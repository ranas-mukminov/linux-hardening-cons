# Security Policy

## Supported versions

Linux Hardening Console tracks the `main` branch. Please report issues against the latest commit on `main`.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Contact the maintainer privately via [run-as-daemon.ru/contact](https://run-as-daemon.ru/contact) or GitHub ([@ranas-mukminov](https://github.com/ranas-mukminov)) and include:

- a description of the issue and its impact,
- steps to reproduce (a PoC if you have one),
- the affected commit and file paths.

Please allow reasonable time for a fix before any public disclosure.
